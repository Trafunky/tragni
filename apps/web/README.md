# web

The Next.js frontend. Part of the pnpm workspace; run commands from the
repository root.

```bash
pnpm --filter web dev     # development server
pnpm --filter web build   # production build
pnpm --filter web lint
```

Setup and troubleshooting: [`docs/development.md`](../../docs/development.md).
Architecture: [arc42 chapter 5](../../docs/architecture/05-building-block-view.md).
